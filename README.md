# منصة إدارة شواهد ومؤشرات المدينة الصحية

نموذج أولي Front-end باستخدام React + JavaScript + Vite.

## التشغيل
1. ثبّت Node.js (إصدار LTS).
2. افتح مجلد المشروع في VS Code.
3. افتح Terminal داخل المجلد ونفّذ:
   ```bash
   npm install
   npm run dev
   ```
4. افتح الرابط الذي يظهر في Terminal (غالبًا http://localhost:5173).

## ما الذي يعمل؟
- لوحة رئيسية تعريفية مع مؤشرات توضيحية موسومة بأنها تجريبية.
- صفحة رفع وإدارة الشواهد.
- رفع ملفات PDF وWord وExcel والصور بالسحب والإفلات أو اختيار الملفات.
- حفظ بيانات الشواهد والملفات محليًا في المتصفح باستخدام IndexedDB.
- بحث وتصنيف ومعاينة الصور وملفات PDF، وتنزيل الملفات أو حذفها.
- صفحة مبسطة للمعايير والمؤشرات والتقارير كواجهات أولية.

## حدود النسخة الحالية
- لا توجد قاعدة بيانات أو خادم أو تسجيل دخول.
- الملفات محفوظة على المتصفح والجهاز الحالي فقط، ولا تتم مشاركتها تلقائيًا مع مستخدمين آخرين.
- الأرقام والبيانات المعروضة تجريبية للتوضيح وليست بيانات أداء فعلية.
- حالات الشواهد تنظيمية داخل النموذج فقط، ولا يوجد مسار اعتماد إلكتروني حقيقي.
- قوائم المحاور والمعايير والجهات أمثلة أولية ويجب استبدالها بالبيانات المعتمدة من الدليل الرسمي.

## هيكل المجلدات
- `src/components`: الشريط العلوي والمكونات المشتركة.
- `src/pages`: الصفحات الرئيسية ورفع الشواهد.
- `src/services`: خدمة التخزين المحلي في IndexedDB.
- `src/data`: البيانات التجريبية.

## تحليل البيانات والمؤشرات
- صفحة مستقلة لتحميل ملفات Excel (XLSX/XLS) وCSV وتحليلها داخل المتصفح.
- اختيار ورقة العمل، معاينة أول 10 صفوف، واستكشاف الأعمدة.
- مؤشرات جودة أولية: عدد السجلات، الخلايا الفارغة، الصفوف المكررة، ومتوسط العمود الرقمي عند تحديده.
- رسوم لتوزيع السجلات حسب عمود تختاره، وتوزيع الحالات عند تحديد عمود الحالة.
- لا يتم افتراض أن أي عمود يمثل نسبة إنجاز أو جهة أو محور؛ يجب اختيار الأعمدة يدويًا.
- التحليل مؤقت للملف المفتوح ولا يُحفظ على خادم أو قاعدة بيانات.
- تمت إضافة اعتمادَي `xlsx` و`recharts`؛ بعد فك الضغط شغّل `npm install` لتثبيتهما.
